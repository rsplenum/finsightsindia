# Design checks — RungGrowth (rung 3)

**Question:** *What if growth is slower than you hope?*

| entry | check | answer |
|---|---|---|
| dd-002 | one question, ≤2 new concepts? | One question, one control, no new concepts. |
| dd-003 | what do they leave with? | That a plan which only works at the top of the range is a hope, not a plan. |
| dd-005 | pushes on the spine? | Directly — it moves the first of the two rates and shows the headroom respond. |
| dd-008 | drag end to end: does any sentence change? | **No.** Verified in the browser across 4%→18%. Prose states a principle; values sit in fixed slots; the one dynamic sentence names the boundary. |

**Deliberate choices**
- The curve is precomputed so dragging is an array lookup. Simulating per position gives either a stutter under the hand or a lag that reads as the tool being unsure.
- The boundary is marked on the track, so the threshold is learned by crossing it rather than by reading.
